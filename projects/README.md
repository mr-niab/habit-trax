# Projects

Home for all apps in this repo. Each project lives in its own folder and deploys
as a sub-path of the Netlify site (e.g. `projects/my-app/` → `https://YOUR-SITE.netlify.app/projects/my-app/`).

## Current apps

| App | Location | Notes |
|---|---|---|
| Habit Tracker | `/` (repo root) | The original app — kept at the root so its deploy URL doesn't change |
| Super Star ⭐ | `/super-star/` | Gold star tracker for kids |

New projects should be added here as `projects/<name>/`, self-contained with their
own `index.html` (no build step), matching the rest of the repo.
